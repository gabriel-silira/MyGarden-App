# Firmware MyGarden

Pasta destinada ao código do Arduino/ESP32 para a futura integração com o aplicativo MyGarden.

**O firmware ainda não foi implementado.** Por enquanto, o aplicativo utiliza dados e irrigação simulados.

Quando o desenvolvimento começar, este README deverá informar a placa utilizada, as ligações dos sensores e da bomba, as dependências, o protocolo de comunicação e como compilar e gravar o firmware.

Senhas de Wi-Fi, credenciais e outros segredos devem ficar em arquivos locais ignorados pelo Git, como `secrets.h` ou `arduino_secrets.h`.

Veja também o [aplicativo Flutter](../app/README.md).
